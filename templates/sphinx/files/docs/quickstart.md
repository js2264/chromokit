# Quickstart

A first result, in three steps.

## Inputs

| File | What it is |
|---|---|
| `input.txt` | The data to read |
| `config.toml` | *(optional)* settings |

## Run it

```python
import {{name}}

result = {{name}}.run("input.txt", threads=4)
print(result.summary())
```

:::{note}
Every function has a command: `{{name}} run input.txt`. Press {kbd}`Ctrl+K` to search.
:::

:::{warning}
A warning. `danger`, `tip` and `important` are drawn too.
:::
