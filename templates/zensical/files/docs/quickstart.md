# Quickstart

A first result, in three steps.

## Inputs

| File | What it is |
|---|---|
| `input.txt` | The data to read |
| `config.toml` | *(optional)* settings |

## Run it

```python
import {{name}}

result = {{name}}.run("input.txt", threads=4)
print(result.summary())
```

!!! note "From the command line"

    Every function has a command: `{{name}} run input.txt`. Press ++ctrl+k++ to search these pages.

!!! warning

    A warning callout. `danger`, `success` and `info` are drawn too.
